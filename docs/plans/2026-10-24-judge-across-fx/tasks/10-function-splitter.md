# 10: Function splitter

**Status:** ready-for-agent
**Blocked by:** 01 (its `scripts/scratch-env` runs every test here; the splitter itself needs nothing)
**Phase:** Review

**What to build:** given a changed file and the lines a diff changed in it, fx can name the functions those lines sit in, in any of the 13 language families of design story 16 (Ruby, TypeScript, JavaScript, Python, Go, Rust, Java, Kotlin, Swift, C#, F#, VB, PHP), and falls back to the changed lines themselves wherever no function can be found. It is one pure module with no judge in it: definitions are found by per-family signature patterns (keywords and visibility modifiers), and each body by brace matching, indentation, or the family's closing keyword. Task 11 uses it to point each lens at the functions its question flags.

**Design:** Implementation Decisions > 8; Testing Decisions

**Files:**
- Create: `src/lib/function-split.ts`, `src/lib/function-split.test.ts`
- Modify: `scripts/check-all`
- Generated by `scripts/build`: `lib/function-split.js`, `lib/function-split.test.js`

**Interfaces:**
- Produces in `src/lib/function-split.ts`:
  - `type LanguageFamily = 'ruby' | 'typescript' | 'javascript' | 'python' | 'go' | 'rust' | 'java' | 'kotlin' | 'swift' | 'csharp' | 'fsharp' | 'vb' | 'php'`
  - `interface FunctionUnit { name: string; startLine: number; endLine: number; text: string }` (1-based, inclusive; `text` is those source lines joined by `\n`)
  - `interface ReviewUnit { name: string | null; startLine: number; endLine: number; text: string }` (`name` `null` for a hunk unit)
  - `languageOf(filePath: string): LanguageFamily | null`, by extension, case-insensitive: `.rb .rake` ruby; `.ts .tsx .mts .cts` typescript; `.js .jsx .mjs .cjs` javascript; `.py` python; `.go` go; `.rs` rust; `.java` java; `.kt .kts` kotlin; `.swift` swift; `.cs` csharp; `.fs .fsx .fsi` fsharp; `.vb` vb; `.php` php; anything else `null`.
  - `splitFunctions(filePath: string, source: string): FunctionUnit[]`: every definition found, in source order, nested ones included; `[]` for a `null` family. Never throws.
  - `reviewUnits(filePath: string, source: string, changedLines: number[]): ReviewUnit[]`: for each changed line, the innermost `FunctionUnit` containing it; changed lines in no unit are grouped into hunk units, a new group starting when the gap to the previous changed line is more than 3 lines; each unit once, in source order. Never throws.
- Body rules: brace families (typescript, javascript, go, rust, java, kotlin, swift, csharp, php) match `{` and `}` from the signature's first `{`, skipping string literals, character literals of the form `'x'` or `'\x'`, line comments and block comments; a signature ending in `=>` or `=` with no `{` on its line (C#, Kotlin, Ruby endless `def x = y`) is a one-line unit, as is a brace body that closes on its own line. python and fsharp take the following lines indented deeper than the signature, blank lines included, up to the last such non-blank line. ruby counts `def`, `class`, `module`, `if`, `unless`, `while`, `until`, `case`, `begin` at statement start and `do` at line end against `end`. vb ends at `End Function`, `End Sub` or `End Property`.
- Name: the identifier the definition binds (`one`, not `self.one`; `Handle` for a Go method with a receiver; `b` for `const b = async function`; `arrow` for `const arrow = (...) => {`).

**Seam:** `splitFunctions`, `reviewUnits` and `languageOf` directly.

**Tests:** each source below is a string with lines joined by `\n`; the expected value lists `name startLine..endLine` of `splitFunctions`.
- ruby, `a.rb`: `class A` / `  def one(x)` / `    if x` / `      1` / `    end` / `  end` / `` / `  def self.two = 2` / `end` gives `one 2..6`, `two 8..8`.
- typescript, `a.ts`: `export async function load(id: string): Promise<void> {` / `  const s = "}";` / `  return;` / `}` / `class B {` / `  private save(x: number): void {` / `    run(() => { x++; });` / `  }` / `}` / `const arrow = (a: number) => {` / `  return a;` / `};` gives `load 1..4`, `save 6..8`, `arrow 10..12`.
- javascript, `a.js`: `function a() {` / `  // }` / `  return 1;` / `}` / `const b = async function () {` / `  return 2;` / `};` gives `a 1..4`, `b 5..7`.
- python, `a.py`: `class C:` / `    def m(self):` / `        x = 1` / `` / `        return x` / `` / `async def top():` / `    pass` gives `m 2..5`, `top 7..8`.
- go, `a.go`: `func (s *Server) Handle(w http.ResponseWriter) {` / `\tif true {` / `\t}` / `}` / `` / `func helper() int { return 1 }` gives `Handle 1..4`, `helper 6..6`.
- rust, `a.rs`: `pub async fn fetch(url: &str) -> Result<(), E> {` / `    let s = '{';` / `    Ok(())` / `}` / `impl X {` / `    fn go(&self) {}` / `}` gives `fetch 1..4`, `go 6..6`.
- java, `A.java`: `public class D {` / `    @Override` / `    public static List<String> names(int n) throws IOException {` / `        return List.of();` / `    }` / `}` gives `names 3..5`.
- kotlin, `a.kt`: `class K {` / `    suspend fun load(id: Int): String {` / `        return ""` / `    }` / `    private fun twice(x: Int) = x * 2` / `}` gives `load 2..4`, `twice 5..5`.
- swift, `a.swift`: `struct S {` / `    func greet(name: String) -> String {` / `        return "hi"` / `    }` / `    init(x: Int) {` / `        self.x = x` / `    }` / `}` gives `greet 2..4`, `init 5..7`.
- csharp, `A.cs`: `public class E` / `{` / `    public async Task<int> RunAsync(CancellationToken ct)` / `    {` / `        return 1;` / `    }` / `    private int Twice(int x) => x * 2;` / `}` gives `RunAsync 3..6`, `Twice 7..7`.
- fsharp, `a.fs`: `let add x y =` / `    x + y` / `` / `let rec loop n =` / `    if n > 0 then` / `        loop (n - 1)` gives `add 1..2`, `loop 4..6`.
- vb, `A.vb`: `Public Class F` / `    Public Function Total(x As Integer) As Integer` / `        Return x` / `    End Function` / `    Private Sub Log()` / `    End Sub` / `End Class` gives `Total 2..4`, `Log 5..6`.
- php, `a.php`: `<?php` / `class G {` / `    public function handle(Request $r): Response {` / `        return new Response('}');` / `    }` / `}` / `function helper() { return 1; }` gives `handle 3..5`, `helper 7..7`.
- `languageOf('x/Y.KT')` is `kotlin`; `languageOf('a.txt')` is `null`; `splitFunctions('a.txt', 'def x():\n  pass')` is `[]`.
- `reviewUnits('a.ts', <the typescript source>, [2, 3])` deep-equals `[{ name: 'load', startLine: 1, endLine: 4, text: <lines 1 to 4> }]`.
- `reviewUnits('a.ts', <the typescript source>, [7])` is the `save` unit (innermost: the arrow on line 7 is not a definition).
- `reviewUnits('a.txt', 'l1\nl2\nl3\nl4\nl5\nl6\nl7\nl8\nl9\nl10', [2, 3, 9])` deep-equals `[{ name: null, startLine: 2, endLine: 3, text: 'l2\nl3' }, { name: null, startLine: 9, endLine: 9, text: 'l9' }]`; with `[2, 5]` it is one unit `2..5`.
- `reviewUnits('a.py', <the python source>, [8, 1])` deep-equals the `class C` line as a hunk unit `1..1` (`name` `null`) followed by the `top` unit `7..8`.
- `splitFunctions` on 200 KB of unbalanced braces (`'{'.repeat(200000)`) in `a.ts` returns within 1,000 ms and does not throw.

**Risks:** a pattern that misses a definition only widens the unit to the hunk, which still reaches the judge; a pattern that misreads a body as too short can hide changed lines from a lens, so a changed line outside every unit always becomes a hunk unit. Quadratic scans on large generated files: one pass per file, and the last test bounds it.

**Testing:** unit tests, one per family plus the fallback and size cases.
