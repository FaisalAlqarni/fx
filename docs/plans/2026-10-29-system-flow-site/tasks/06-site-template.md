**Interfaces:**
- Consumes: merged sections with `role`, `lead` (task 02); `Look` (task 01); `goodSet()` with the Start here chapters (task 03); sequence `rows` with `leaves` and `assets/fx-flow-2.js` (task 05).
- Produces, the template slots: `TITLE`, `NAME`, `HEADER`, `LEGEND`, `MENU`, `CHAPTERS`, `MAP_DATA`, `DIAGRAMS`, `SITE_INDEX`, `FOOTER` (as `<!-- slot: NAME -->` markers, like the kit template). `SITE_INDEX` is left empty until task 08.
- Produces, the DOM contract (tasks 07, 08, 11 and `page-check.js` use these names only):
  - The menu column is `<aside id="side">` holding, in order: `<p class="menu-name">` (the `meta.name`), `<p class="menu-sub">` (`System flow, generated by fx`), `<button id="theme" type="button">`, then `<details id="menu-bar">` (no `open` attribute in the markup) whose `<summary>` reads `Chapters` and whose only other child is `<nav id="menu" aria-label="Chapters">`. `button#theme` is a sibling of `#menu-bar`, never inside `<summary>`: a control nested in a summary breaks the summary's button role.
  - In `#menu`: `section.group[data-group="start"|"how"|"ref"]`, each with an `h2` (`Start here`, `How it works`, `Reference`) and an `ol` (numbered) or `ul` (Reference) of `<a href="#<chapter id>">`. `#menu` is the element that scrolls when the list is taller than the window (`overflow:auto`); `#side` is the sticky column.
  - The template script: on load, and on every `change` event of `matchMedia('(min-width: 900px)')`, it sets `#menu-bar.open` to the query's `matches` (open at 900 px and up, closed below). Below 900 px, choosing a link or pressing Escape closes `#menu-bar` and returns focus to its summary.
  - Without JavaScript `#menu-bar` stays closed. At 900 px and up CSS still shows the list: inside `@media (min-width: 900px)` an `@supports selector(::details-content)` block sets `#menu-bar::details-content` to `content-visibility:visible; display:block` and hides the summary. A browser without `::details-content` keeps the summary visible, and its `Chapters` summary opens the list (accepted).
  - Below 900 px: `#side` is the sticky top bar; `.menu-name`, `button#theme` and the `summary` sit in one row (`.menu-sub` hidden); the open `#menu` panel lies under that row, at most the window height less the row, and scrolls on its own.
  - Chapters: `<section class="chapter" id="ch-<NN>-<section id>" data-group="start"|"how">`; Reference chapters `id="glossary"`, `"rules-in-force"`, `"coverage"`, `"corrections"` with `data-group="ref"`.
  - Chapter head: `<p class="eyebrow"><span class="n">NN</span> <span class="q">question</span></p>`, `<h2>`, `<p class="lead">`, `<ul class="facts">` with one `<li>` per bullet holding the text and `<code class="at">path:lines</code>` (the first file evidence).
  - Scroll spy: the current chapter's menu link has `aria-current="location"` (observer `rootMargin: -40% 0px -55% 0px`); the menu scrolls itself, never the page.
  - Legend: `<ul class="legend">`, one `<li data-look="<look>">` per look the model uses, labelled `Part of <name>`, `Data or files`, `Phone or browser`, `Outside <name>`, `Security or identity check`, then `Call that leaves <name>` (when any sequence has a leaving call) and `Step in flight`.
