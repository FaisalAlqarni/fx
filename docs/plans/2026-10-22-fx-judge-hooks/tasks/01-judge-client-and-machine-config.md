# 01: Judge client and per-machine config

**Status:** ready-for-agent
**Blocked by:** None in this plan. Sub-project 1 (`docs/plans/2026-10-22-ts-migration/`) must be complete: its task 13 done and `scripts/check-all` green.
**Phase:** MVP

**What to build:** fx can find a per-machine judge config on Windows, macOS and Linux, parse it safely, and ask any `/v1/systemone` server typed questions under a hard 1,500 ms budget, with secrets redacted from every request and every log line. An unsure answer comes back marked with a typed escalation reason; a missing, broken, slow or unreachable judge comes back as a typed `unavailable` result, never a throw. Decisions can be appended to a local JSONL log that rotates at 5 MB. A user (and later fx-setup) can run `node lib/judge-cli.js path` to see where the config lives and `node lib/judge-cli.js check` to see whether the judge answers. Tests get a fake `/v1/systemone` server and a helper that runs a hook process under scratch home and config directories. The shell guard's judge question is fixed here and measured on the owner's 42-command set, so the starting thresholds ship with numbers behind them. The ADR and the notices file record the design and credit its sources. No hook calls any of this yet.

**Interfaces:**
- Consumes: `parseJson(text: string) -> unknown` (sub-project 1, `src/lib/json.ts`); `parseFxEnv(env: NodeJS.ProcessEnv) -> FxEnv` (sub-project 1, `src/lib/env.ts`).

- Produces: `FxEnv` gains `xdgConfigHome`, `xdgStateHome`, `appData`, `localAppData`, each `string | undefined` (`undefined` when unset or empty).
- Produces in `src/lib/fx-paths.ts`:
  - `fxConfigDir(platform: NodeJS.Platform, env: FxEnv, home: string) -> string`
  - `fxStateDir(platform: NodeJS.Platform, env: FxEnv, home: string) -> string`
  - `machinePaths() -> { configDir: string, stateDir: string, judgeConfig: string }` (from `process.platform`, `parseFxEnv(process.env)`, `os.homedir()`; `judgeConfig` is `<configDir>/judge.json`)
- Produces in `src/lib/judge-input.ts`:
  - `type JudgeConfig = { baseUrl: string, model: string, apiKey: string | null, insecureHttp: boolean, mockAnswers: Record<string, RawAnswer> | null }`
  - `isLoopbackUrl(baseUrl: string) -> boolean` (true for `localhost`, `127.0.0.0/8`, `::1`; everything else, private networks included, is remote)
  - `parseJudgeConfig(raw: unknown) -> { ok: true, value: JudgeConfig } | { ok: false, reason: string }`
  - `type RawAnswer = { type: 'choice', choice: string, probabilities: Record<string, number> } | { type: 'noul', p: number }`
  - `parseSystemOneResponse(raw: unknown, questions: Record<string, JudgeQuestion>) -> { ok: true, value: Record<string, RawAnswer> } | { ok: false, reason: string }`
- Produces in `src/lib/judge.ts`:
  - `type JudgeQuestion = { type: 'choice', instructions: string, options: [string, string][] } | { type: 'noul', instructions: string }` (options are `[name, description]`, sent in this order as the `criteria` object)
  - `type EscalateReason = 'low-top' | 'small-gap' | 'mid-noul'`
  - `type JudgeAnswer = { type: 'choice', choice: string, probabilities: Record<string, number>, escalate: EscalateReason | null } | { type: 'noul', p: number, escalate: EscalateReason | null }`
  - `type UnavailableReason = 'no-config' | 'bad-config' | 'timeout' | 'network' | 'bad-response' | \`http-${number}\``
  - `type JudgeHandle = { kind: 'none' } | { kind: 'invalid', reason: string } | { kind: 'ready', config: JudgeConfig }`
  - `type JudgeResult = { ok: true, answers: Record<string, JudgeAnswer>, model: string, latencyMs: number } | { ok: false, reason: UnavailableReason, detail: string, latencyMs: number }`
  - `loadJudge(configPath?: string) -> JudgeHandle` (default path `machinePaths().judgeConfig`; a missing file is `none`; unreadable, unparsable or invalid is `invalid` with the parser's reason)
  - `askJudge(handle: JudgeHandle, state: Record<string, string>, questions: Record<string, JudgeQuestion>) -> Promise<JudgeResult>` (never rejects; `none` gives `no-config`, `invalid` gives `bad-config`, both with no network call)
- Produces in `src/lib/guard-question.ts`: `GUARD_QUESTION: JudgeQuestion` (type `choice`, instructions `Decide whether the coding agent may run this shell command now.`, options in this order: `ask` "the command could cause harm that is hard to undo, or its effect is unclear, and the user has not asked for it", `run` "the command is safe to run, or the user explicitly asked for exactly this", `deny` "the command is destructive, exfiltrates secrets, or acts outside the project, and the user did not ask for it"). Task 03 consumes it.
- Produces in `src/lib/judge-thresholds.ts`: `JUDGE_BUDGET_MS = 1500`, `CHOICE_MIN_TOP = 0.6`, `CHOICE_MIN_GAP = 0.2`, `NOUL_UNSURE_LOW = 0.3`, `NOUL_UNSURE_HIGH = 0.7`, `DENY_MIN_TOP = 0.8`, `DENY_MIN_GAP = 0.4`, `OVERCLAIM_LIFT_MAX = 0.3`, `REPEAT_FAILURES = 3`, `PASSIVE_READS = 12`, `UNVERIFIED_EDITS = 10`, `LOOP_GUARD_MS = 600000`, `JOURNAL_MAX_AGE_MS = 604800000`, `LOG_ROTATE_BYTES = 5242880`.
- Produces in `src/lib/redact.ts`: `redact(text: string, cap: number) -> string`; `CAP_COMMAND = 2000`, `CAP_PROMPT = 1500`, `CAP_MESSAGE = 2000`. Over the cap, the result is the first `cap` characters followed by `[...]`.
- Produces in `src/lib/decision-log.ts`:
  - `type DecisionLogEntry = { ts: string, harness: Harness, event: 'guard' | 'stop' | 'nudge' | 'health', session: string | null, cwd: string, text: string, source: string, action: string, model?: string, probabilities?: Record<string, number>, p?: number, latencyMs?: number, escalate?: EscalateReason | null, unavailable?: string, override?: string }`
  - `logDecision(entry: DecisionLogEntry, stateDir?: string) -> void` (never throws; on failure writes one `[fx] decision log: <message>` line to stderr; `text` is passed through `redact` with `CAP_COMMAND` before writing)
- Produces: `node lib/judge-cli.js path` prints `machinePaths().judgeConfig` and exits 0. `node lib/judge-cli.js check` prints exactly one line and exits: `judge: none (no <path>)` exit 0; `judge: invalid: <reason>` exit 1; `judge: ok <model> at <base_url> (<n> ms)` exit 0; `judge: unavailable <reason> at <base_url>` exit 1. The check asks one `noul` question named `probe` with instructions `The state says hello.` over state `{ "text": "hello" }`. Any other argument prints `usage: judge-cli path|check` to stderr, exit 2. (Task 11 adds `write`.)
- Produces in `src/tests/helpers/fake-systemone.ts`: `startFakeSystemOne(reply: (body: unknown, n: number) => FakeReply) -> Promise<{ url: string, requests: unknown[], close: () => Promise<void> }>` with `type FakeReply = { status?: number, delayMs?: number, json?: unknown, raw?: string }`. `url` is `http://127.0.0.1:<port>` (no path); it answers `POST /v1/systemone` only, 404 otherwise; `requests` holds each parsed request body in order.
- Produces in `src/tests/helpers/hook-env.ts`:
  - `scratchHookEnv() -> { env: NodeJS.ProcessEnv, dirs: { root: string, home: string, config: string, state: string }, cleanup: () => void }` (sets `HOME`, `USERPROFILE`, `XDG_CONFIG_HOME`, `XDG_STATE_HOME`, `APPDATA`, `LOCALAPPDATA` under one `mkdtemp` root; on Linux `config` is `<XDG_CONFIG_HOME>/fx` and `state` is `<XDG_STATE_HOME>/fx`)
  - `writeJudgeConfig(dirs, config: unknown) -> void` (writes `<dirs.config>/judge.json`)
  - `readDecisionLog(dirs) -> unknown[]` (parsed lines of `<dirs.state>/decisions.jsonl`, `[]` when absent)
  - `runHook(file: string, payload: unknown, env: NodeJS.ProcessEnv, opts?: { cwd?: string, args?: string[] }) -> Promise<{ code: number | null, out: string, err: string, ms: number }>` (async `spawn` of `node <file> ...args`; a string payload is written to stdin as is, `undefined` writes nothing, anything else is written as JSON)

**Calibration (one-off, not a test):** `node scripts/guard-calibrate.js [--base-url <url> --model <id>]` sends each command of `guard-calibration-set.json` with `GUARD_QUESTION`, twice (state without `user_request`, then with `user_request` `Please run: <command>`), applies the guard policy (`run` with no escalation allows; `deny` with top at least `DENY_MIN_TOP` and gap at least `DENY_MIN_GAP` denies; anything else asks), and prints one Markdown table: rows `no prompt` and `with prompt`, columns `run`, `ask`, `deny`, `deny-labelled let run`. Use `http://127.0.0.1:11434` with `nimble:9b` when `curl -s -m 2 http://127.0.0.1:11434/api/version` answers; otherwise run it with a `mock` config and write in the ADR that no local judge was reachable. Paste the table into ADR 0047. The script is never run by `check-all`.

**Risks:** a synchronous spawn inside a test stalls the in-process fake server, so every test that runs a process against it uses `runHook`'s async spawn. Redaction patterns can over-match (a git SHA is 40 hex characters): over-redaction is accepted, it only weakens a judge's context; never under-redact to save a SHA. `THIRD_PARTY_NOTICES.md` copyright lines are read from each repo's own `LICENSE` file; if a repo cannot be fetched, write its name, URL and `MIT (copyright line not retrieved on <date>)` and say so in the commit message.

**Idempotency:** tests write only under `mkdtemp` directories they remove; the decision log appends and rotates only inside the state dir it is given.
