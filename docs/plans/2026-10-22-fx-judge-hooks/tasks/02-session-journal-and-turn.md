# 02: Session journal and the turn on Claude Code

**Status:** ready-for-agent
**Blocked by:** 01
**Phase:** MVP

**What to build:** fx keeps an append-only journal per session on the machine and knows where a turn starts. On Claude Code, every user prompt is recorded (redacted and capped) at `UserPromptSubmit` through a new hook entry point, and a subagent's turn starts at its `SubagentStart`, recording the agent type. A prompt event that carries an `agent_id` is a parent's dispatch text, never a user prompt: it starts the subagent's turn only. A prompt starting `[fx] ` is fx's own continuation and is ignored. Every string is redacted before it reaches the journal. A repo can switch the coming judge step, Stop check and nudges off in `.fx.json` under a new `hooks` key, read from the git top level, never from a directory the agent `cd`'d into below it. The existing hook tests move onto scratch home, config and state directories, so nothing fx writes from now on can touch a developer's real home during a test. No decision changes yet: the session behaves exactly as before.

**Interfaces:**
- Consumes: `fxStateDir`, `machinePaths` (task 01); `redact`, `CAP_PROMPT` (task 01); `JOURNAL_MAX_AGE_MS` (task 01); `scratchHookEnv`, `runHook` (task 01); `parseFxJson` (sub-project 1); `parseClaudeHookInput` (sub-project 1).
- Produces in `src/lib/types.ts`:
  - `type ToolKind = 'edit' | 'read' | 'shell' | 'other'`
  - `type NudgeSignal = 'repeat-failure' | 'passive-stall' | 'unverified-writes'`
  - `type JournalEvent = { t: number, kind: 'prompt', text: string | null, agentType?: string | null } | { t: number, kind: 'tool', tool: ToolKind, command: string | null, outcome: 'ok' | 'fail' | 'unknown', verified: boolean } | { t: number, kind: 'edit', path: string } | { t: number, kind: 'deny', command: string } | { t: number, kind: 'ask', command: string } | { t: number, kind: 'nudge', signal: NudgeSignal } | { t: number, kind: 'stop-block' }` (`t` is epoch milliseconds)
- Produces in `src/lib/journal.ts`:
  - `journalKey(sessionId: unknown, agentId?: unknown) -> string | null` (`null` unless `sessionId` is a non-empty string; every character outside `[A-Za-z0-9._-]` becomes `_`; `<session>__<agent>` when `agentId` is a non-empty string)
  - `appendEvent(key: string, ev: JournalEvent, stateDir?: string) -> void` (one `appendFileSync` of one line to `<stateDir>/sessions/<key>.jsonl`, directories created, file mode `0600`; every string field passes through `redact` with `CAP_COMMAND` first (prompt text with `CAP_PROMPT`); never throws; a failure writes one `[fx] journal: <message>` line to stderr)
  - `readJournal(key: string, stateDir?: string) -> JournalEvent[]` (missing file is `[]`; lines `parseJournalLine` rejects are skipped)
  - `currentTurn(events: JournalEvent[]) -> JournalEvent[]` (events after the last `prompt` event, that event excluded; every event when there is none)
  - `lastUserPrompt(sessionId: string, stateDir?: string) -> string | null` (the `text` of the last `prompt` event in the root key's journal; `null` when absent or when that text is `null`)
  - `pruneJournals(now: number, stateDir?: string) -> void` (deletes `sessions/*.jsonl` whose mtime is older than `now - JOURNAL_MAX_AGE_MS`; never throws)
  - `stateDir` defaults to `machinePaths().stateDir` everywhere.
- Produces in `src/lib/session-input.ts`: `parseJournalLine(raw: unknown) -> JournalEvent | null`.
- Produces in `src/lib/repo-config.ts`:
  - `type HookSwitches = { shellJudge: boolean, stopCheck: boolean, loopNudge: boolean }` (renamed from the first draft's `shellGuard`: the switch now turns off only the judge step, red team C1)
  - `type CheckCommands = { test_one: string | null, test_scope: string | null, test_all: string | null, lint: string | null, setup: string | null }`
  - `repoRoot(cwd: string) -> string` (`git rev-parse --show-toplevel` run in `cwd` with a 2,000 ms timeout; `cwd` itself when git fails, times out or `cwd` is outside a repository)
  - `readRepoConfig(cwd: string) -> { hooks: HookSwitches, checks: CheckCommands }` (reads `<repoRoot(cwd)>/.fx.json`; missing or unreadable file gives every switch `true` and every check `null`)
- Produces: `parseFxJson`'s `value.hooks` as `{ shell_judge?: boolean, stop_check?: boolean, loop_nudge?: boolean }` (an unknown member such as `shell_guard` is ignored); a non-object `hooks` gives problem `{ key: "hooks", reason: "hooks must be an object" }`; a non-boolean member gives `{ key: "hooks.<name>", reason: "hooks.<name> must be a boolean" }` and that member is left out.
- Produces: `hooks/fx-turn.js`, routed on `hook_event_name`. This task handles `UserPromptSubmit` only: a prompt starting with `[fx] ` is ignored; with an `agent_id` it appends `{ kind: 'prompt', text: null }` to `journalKey(session_id, agent_id)` only; otherwise it appends `{ kind: 'prompt', text: redact(prompt, CAP_PROMPT) }` to `journalKey(session_id)`. It prints nothing and exits 0. Every other event, malformed input and any failure: prints nothing, exits 0 (a `UserPromptSubmit` exit 2 would block the user's prompt, so this entry point never exits 2), failures with one stderr line starting `[fx]`.
- Produces: `hooks/hooks.json` gains `"UserPromptSubmit": [{ "hooks": [{ "type": "command", "command": "node \"${CLAUDE_PLUGIN_ROOT}/hooks/fx-turn.js\"", "timeout": 5 }] }]`.
- Produces: Claude `SubagentStart` (in `fx-context`) appends `{ kind: 'prompt', text: null, agentType: <agent_type when a string, else null> }` to `journalKey(session_id, agent_id)` before printing; its printed output is unchanged.

**Seam:** `hooks/fx-turn.js` and `hooks/fx-context.js` as processes; unit tests for the journal, parser and repo config.

**Tests:**
- `journalKey('s/1', 'a 1')` gives `s_1__a_1`; `journalKey('', 'a')` gives `null`; `journalKey('s1')` gives `s1`.
- `currentTurn` over `[tool, prompt, edit, tool]` gives `[edit, tool]`; over `[edit]` gives `[edit]`.
- `readJournal` over a file holding a valid prompt line, the line `garbage`, and a valid edit line gives two events.
- `pruneJournals(now)`: a journal with mtime `now - 8 days` is deleted, one with `now - 6 days` is kept.
- `parseJournalLine({ t: 1, kind: 'edit', path: 'a.ts' })` gives that event; `{ t: 1, kind: 'edit' }` gives `null`; `{ t: 'x', kind: 'prompt', text: null }` gives `null`.
- `readRepoConfig` on a directory with no `.fx.json`: all three switches `true`, all five checks `null`. With `{"hooks":{"stop_check":false},"test_all":"make test","setup":"make setup"}`: `stopCheck` `false`, `shellJudge` and `loopNudge` `true`, `checks.test_all` `"make test"`, `checks.setup` `"make setup"`. With `{"hooks":{"shell_judge":"no"}}`: `shellJudge` `true`.
- `readRepoConfig` from `<repo>/sub` of a scratch git repo whose top level holds `{"hooks":{"stop_check":false}}` and whose `sub/.fx.json` holds `{"hooks":{"stop_check":true,"shell_judge":false}}`: `stopCheck` `false`, `shellJudge` `true` (the top level wins; `sub/` is never read). From a scratch directory outside any repo: its own `.fx.json`.
- `parseFxJson({ hooks: { shell_judge: 'no', loop_nudge: false } })`: `value.hooks` equal to `{ loop_nudge: false }`, problems `[{ key: "hooks.shell_judge", reason: "hooks.shell_judge must be a boolean" }]`.
- `appendEvent('s1', { t: 1, kind: 'tool', tool: 'shell', command: 'export TOKEN=abcdef1234567890abcdef1234567890abcdef12', outcome: 'ok', verified: false })` then `readJournal('s1')`: the stored `command` contains `[REDACTED]` and not `abcdef1234567890`.
- Process, `fx-turn` (`tests/gates/turn-journal.test.js`):
  - `{"hook_event_name":"UserPromptSubmit","session_id":"s1","cwd":<tmp>,"prompt":"deploy with token=abc123def456ghi789"}`: exit 0, stdout `""`, and `<state>/sessions/s1.jsonl` holds one line whose `kind` is `prompt` and `text` is `deploy with token=[REDACTED]`;
  - a second prompt in `s1`: the file holds two lines;
  - `{"hook_event_name":"UserPromptSubmit","session_id":"s1","agent_id":"a1","agent_type":"default","prompt":"implement task 3"}`: `s1.jsonl` is unchanged and `s1__a1.jsonl` holds one `prompt` line with `text` `null`;
  - prompt `[fx] This turn edited files and no check has passed since the last edit.` in `s1`: no line is added anywhere;
  - the same payload without `session_id`: exit 0, stdout `""`, no file under `<state>/sessions/`;
  - stdin `not json`: exit 0, stdout `""`;
  - `XDG_STATE_HOME` pointing at a regular file: exit 0, stdout `""`, stderr starts with `[fx] journal:`;
  - `{"hook_event_name":"Stop","session_id":"s1"}`: exit 0, stdout `""` (handled from task 09 on).
- Process, `fx-context` SubagentStart `{"hook_event_name":"SubagentStart","session_id":"s1","agent_id":"a1","cwd":<tmp>}`: stdout byte-identical to the golden gate's recorded SubagentStart output for the same cwd, and `<state>/sessions/s1__a1.jsonl` holds one `prompt` line with `text` `null` and `agentType` `null`; with `"agent_type":"fx-lens-security"` in the payload, `agentType` is `fx-lens-security`.
- `hooks/hooks.json` parses and its `UserPromptSubmit` entry command is exactly `node "${CLAUDE_PLUGIN_ROOT}/hooks/fx-turn.js"`.
- Existing, unchanged expected outputs: `node tests/gates/hook-output-golden.test.js`, `node tests/gates/transcript-path.test.js`, `node tests/gates/dispatch-route.test.js`: exit 0 with no fixture changed.

**Risks:** sub-project 1's golden gate copies `hooks/` and `lib/` into a scratch tree for its failed-load cases: the copy now needs `lib/journal.js`, `lib/redact.js` and their requires, which a full-directory copy already gives; if the gate copies a file list, extend the list. A hook that loads `lib/journal` at the top unguarded would turn a broken journal into a crashed context hook: load it as a typed `require` inside `try`, failure means no journal.

**Idempotency:** the journal is append-only under the state dir; tests use scratch state dirs they remove.

**Testing:** unit tests, the new process gate, the existing golden, transcript-path and dispatch-route gates, `scripts/check-all`.
